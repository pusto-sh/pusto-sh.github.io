# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

A simple landing page for the owner's domain, pusto.sh, built around the supplied landscape image.

## Capabilities and Constraints

- Host in `pusto-sh/pusto-sh.github.io` using GitHub Pages.
- Preserve the image's gradient, texture, and brushstroke detail without compression artifacts.
- Use lossless compression and retain the original asset.

## Brand Commitments

The supplied `pustosh.png` artwork is the visual authority.

## Implementation Assumptions

Plain static HTML/CSS is sufficient. Only the image is visible. The artwork fills the viewport, with a crop on narrower screens that keeps the circle visible. The phone crop was offered as a preference and remains adjustable.
